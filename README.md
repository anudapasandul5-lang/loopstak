# Loopstak

Website for Loopstak, an automation business: productized websites, lead capture and booking, and AI automation for small businesses.

**Stack:** Next.js 16, React 19, Tailwind CSS 4.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in values
npm run dev                  # http://localhost:3000
```

Other scripts: `npm run build`, `npm run start`, `npm run lint`.

## Project notes

- `PRODUCT.md`: what the business sells and to whom
- `DESIGN.md`: visual direction
- `CLAUDE.md` / `AGENTS.md`: instructions for AI coding agents
